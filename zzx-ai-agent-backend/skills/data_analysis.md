# Data Analysis Skill

This skill helps you analyze data, create visualizations, and derive insights.

## Capabilities

- Calculate summary statistics (mean, median, std, percentiles)
- Create charts and visualizations (bar, line, scatter, heatmap)
- Identify trends, patterns, and outliers
- Perform correlation and regression analysis

## Common Analysis Patterns

### Trend Analysis
To identify trends, look at data over time:
- Calculate moving averages to smooth noise
- Compare year-over-year or month-over-month changes
- Use seasonal decomposition for cyclical data

### Outlier Detection
Flag potential outliers using:
- Z-score > 3 or < -3
- IQR method: points outside 1.5 * IQR from quartiles
- Domain-specific thresholds

## Visualization Tips

- Bar charts for categorical comparisons
- Line charts for time series
- Scatter plots for correlation
- Heatmaps for matrix data
